# Как запустить измерения

Скрипты нужно положить в свой репозиторий рядом с каталогом `service/`.
Структура должна быть примерно такой:

```text
userver-build-research/
├── service/
├── scripts/
│   ├── reproduce.sh
│   └── reproduce_in_docker.sh
└── README.md
```

В обычном терминале Ubuntu, из корня репозитория, выполнить:

```bash
chmod +x scripts/reproduce.sh scripts/reproduce_in_docker.sh
./scripts/reproduce.sh
```

Первый скрипт записывает информацию о компьютере, запускает нужный Docker-образ
и вызывает второй скрипт внутри контейнера. Второй скрипт собирает Clang Build
Analyzer, настраивает сервис и измеряет два варианта: исходный и изменённый. 
Для всех сборок используются одинаковые
настройки: Clang 14, Release, `-ftime-trace` и две параллельные задачи сборки.

После окончания скрипт напишет путь к папке с результатами. В ней будут:

- `host-hardware.txt` — операционная система, процессор и память компьютера;
- `*.bin` — данные Clang Build Analyzer;
- `*-analysis.txt` — текстовые отчёты анализатора.
- `*-container.log` — логи контейнера докера.

Скрипт временно меняет два исходных файла для измерения исходного варианта, а
затем возвращает вариант с `component.hpp`. Не редактируйте эти файлы, пока
скрипт работает.
